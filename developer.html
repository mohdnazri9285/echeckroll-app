Alat Debug & Reset

Reset Data

Padam semua data yang disimpan dalam localStorage. Ini akan mengembalikan sistem ke keadaan asal (kosong).

Reload Mock Data

Jika anda telah padam data atau mahu memulakan ujian dari awal, klik butang ini untuk memuatkan semula Mock Data (10 kumpulan, 3 Rancangan, Pengguna Demo).

Semak Struktur Data

Paparkan struktur data semasa yang tersimpan dalam localStorage untuk semakan.

Klik butang di atas untuk melihat data...

Log Sistem (Console)

Nota kepada Pembangun: Sila gunakan F12 -> Console untuk melihat log terperinci. Anda juga boleh klik butang di bawah untuk membersihkan log console.
